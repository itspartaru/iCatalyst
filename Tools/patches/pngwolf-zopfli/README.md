# Патчи для pngwolf-zopfli

Применяются `Tools/build_tools.py` по алфавиту, перед `cmake`, каждый через
`git apply --check` — поэтому повторный запуск сборки безопасен, а уже
применённый или неприменимый патч только сообщается и пропускается.

Имена: `NNNN-краткое-описание.patch`. В заголовке каждого патча укажите, какая
версия компилятора его потребовала.

Зачем это здесь заранее: pngwolf-zopfli не менялся с 2017 года и вендорит GAlib
1996 года. Под GCC 13 вероятны отказы вида «`uint32_t` does not name a type» или
«`memcpy` was not declared in this scope» — не хватает транзитивных
`#include <cstdint>` и `<cstring>`, которые старые версии libstdc++ подтягивали
сами. Ожидаемый объём — от нуля до трёх однострочных патчей.

Провал сборки pngwolf не фатален: режим Xtreme откатывается на zopfli через
oxipng, о чём сообщает одна строка предупреждения.
